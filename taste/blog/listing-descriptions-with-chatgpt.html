How to write listing descriptions with ChatGPT or Claude

By T, Steele Software, Raleigh

If AI listing copy keeps coming back “stunning” and “must-see,” the problem is usually the brief, not the tool. Give it the same four things you would give a good copywriter.

Why the first draft sounds generic

“Write a listing description for a 3-bed house” gives the model almost nothing to work with, so it fills the gaps with the most common phrases it has seen. Specific facts in, specific copy out.

The four-part brief

  1. Context. The facts that matter: beds and baths, square footage, updates with years, the lot, what is nearby and how far.
  2. Ask. What you want back: a listing description, five social captions, or a “Just Listed” email.
  3. Format. Length, tone and rules: “120 words, plain English, no clichés, describe the home, not the buyer.”
  4. Example. Paste one of your best past descriptions so it matches your voice.

A prompt you can copy

Context: 3-bed, 2-bath ranch, 1,850 sq ft. New roof in 2024. Screened back porch. Fenced yard. Greenway 0.4 miles away.
Ask: Write the MLS listing description.
Format: About 120 words. Plain, warm, specific. No "stunning," "nestled" or "must-see." Describe the property and its features, never the type of buyer.
Example: [paste one of your own past descriptions here]

Check before you post

  • Every fact matches the listing sheet. AI can invent details, so check numbers and features line by line.
  • It describes the home, not who should live there. See the fair housing checklist.
  • It sounds like you. If not, add a second example and ask for a rewrite.

Save it so you never start from scratch

Put the brief and two or three of your best descriptions into a ChatGPT project or a Claude project. Next time you only paste the new property’s facts.

Same tool, better brief

A sample from a team session: rewriting a listing.

Before: generic prompt
Write a listing description for a 3-bed house.
Generic "stunning, must-see" output
After: a C.A.F.E. brief
Context: 3-bed ranch, new roof, fenced yard, two blocks from a park. Describe the property, not the buyer. Ask: listing description. Format: 120 words, no clichés. Example: [our best recent listing]
